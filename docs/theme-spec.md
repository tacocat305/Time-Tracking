# Theme Spec

## Default Appearance

- Default theme: `Summer`
- Default color mode: `Light`

## Seasonal Themes

- `Summer`: bright linen backgrounds, coastal blues, and fresh citrus accents
- `Fall`: warm amber neutrals, chestnut surfaces, and muted rust accents
- `Winter`: crisp slate surfaces, frosted neutrals, and deep blue accents
- `Spring`: soft stone backgrounds, moss greens, and floral coral accents

## Modes

Each seasonal theme supports:

- `Light` mode for the default day-to-day workspace
- `Dark` mode for lower-glare reviewing and evening sessions

## UI Direction

The visual goal is boutique-professional:

- warm and polished rather than cold and corporate
- clear enough for long work sessions
- restrained contrast, soft surfaces, and deliberate accent color
- professional typography with a little personality

## Implementation Status

Theme selection and light/dark mode are persisted with the desktop workspace. The grouped theme picker, palette previews, and Summer Light default are implemented.
